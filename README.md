# فكّ التخبيص | Fakk Al-Takhbees

إضافة Chrome لتحويل النص بين تخطيطي لوحة المفاتيح **Arabic (101)** و **English (US) QWERTY**. ليست ترجمة ولا تصحيحًا إملائيًا؛ إنها تعكس الأحرف بحسب مواضع المفاتيح.

## المميزات
- نافذة منبثقة لتحويل النص في الاتجاهين.
- قائمة سياقية لتحويل النص المحدد في الصفحة.
- اختصار لوحة مفاتيح قابل للتغيير من صفحة اختصارات Chrome: `Alt+Shift+K` افتراضيًا.
- حفظ محلي لآخر نص وإعدادك باستخدام `chrome.storage.local`.
- معالجة محلية؛ لا تُرسل النصوص إلى خادم.
- خيار للتحكم بدمج تراكيب لام-ألف مثل «لا/لأ/لإ/لآ».

## التثبيت من المصدر
1. نزّل المستودع أو استخدم `git clone https://github.com/MR-SPH/fakk-al-takhbees-chrome.git`.
2. افتح `chrome://extensions`.
3. فعّل **Developer mode / وضع المطوّر**.
4. اختر **Load unpacked / تحميل إضافة غير مضغوطة** وحدد مجلد المشروع.
5. افتح الإضافة من شريط الأدوات.

## الاستخدام
- الصق النص في خانة الإدخال.
- اختر الاتجاه المناسب.
- انسخ النتيجة.
- لتحويل نص محدد في صفحة، حدده ثم افتح قائمة الزر الأيمن واختر اتجاه التحويل.

## فحص المشروع وتجهيزه
على Linux أو WSL أو Git Bash:
```bash
bash scripts/check.sh
bash scripts/package.sh
```
ينتج أمر التغليف ملف `dist/fakk-al-takhbees-chrome.zip` مناسبًا للتوزيع اليدوي. لم يُضمّن ملف ZIP مولّد في المستودع.

## ملاحظات التوافق
الخريطة مصممة لتخطيطي Arabic 101 وUS QWERTY. قد تختلف النتيجة مع تخطيطات عربية أخرى أو إعدادات خاصة. افحص النتيجة قبل استبدال نص مهم. لا يضمن الاختصار العمل على صفحات Chrome الداخلية أو صفحات المتجر.
